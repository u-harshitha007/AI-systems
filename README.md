# AI Systems

This repository contains my structured learning journey in Artificial Intelligence and AI Systems development. It includes practical implementations, experiments, and projects developed while learning the fundamentals of LLM-based applications and related technologies.

## Week 1 — Day 1: First LLM Application

The first project focuses on making a basic Large Language Model (LLM) API call using Python and the Groq API.

### Objectives

- Set up a Python development environment using `uv`
- Understand project and dependency management
- Configure environment variables securely
- Integrate an LLM API with a Python application
- Understand the basic request and response flow of an LLM application
- Manage the project using Git and GitHub

### Technologies

- Python
- Groq API
- Large Language Models (LLMs)
- uv
- Git
- GitHub
